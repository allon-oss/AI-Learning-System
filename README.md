# Personal Learning System（个人学习系统）

这是我的第一个 Codex 项目。

这个项目的目标不是一开始就做一个复杂的软件，而是一步一步搭建一个适合自己使用的个人学习系统。它会帮助我整理不同领域的学习资料、规划学习任务、记录学习笔记、复盘学习进度，并在后续逐步加入 AI 辅助能力。

V1 第一阶段主要服务两个真实学习方向：

- AI 学习
- 雅思英语学习

未来可以扩展到专业学习、工作技能、阅读和其他长期成长目标。

## 项目目标

我希望这个系统最终可以帮助我完成这些事情：

- 记录正在学习的主题
- 保存课程、文章、视频、书籍等学习资料
- 制定每日或每周学习计划
- 写学习笔记和复盘
- 跟踪学习进度
- 后续使用 AI 帮我总结、解释、推荐下一步学习内容

## 当前阶段

当前项目处于第 0 阶段末尾：V1 需求已经确认，准备进入 V1 开发阶段。

V1 的最终范围已经明确：

- 学习主题管理
- 学习资料管理
- 今日学习计划
- 学习笔记
- 学习进度记录

V1 暂时不做 AI 自动总结、AI 自动规划、RAG 知识库、纸质资料拍照识别、用户登录、云同步、复杂图表和手机 App。

## 建议开发原则

作为新手，我会遵守几个原则：

- 先理解，再开发
- 先做小功能，再做复杂功能
- 先让项目能用，再让项目漂亮
- 每一步都写清楚原因
- 不为了炫技而增加复杂度
