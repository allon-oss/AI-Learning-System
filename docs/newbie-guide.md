# 新手入门说明

这份文档帮助零基础用户理解这个项目。

## 这个项目是什么

这是一个 Personal Learning System（个人学习系统）。

它不是一开始就很复杂的产品，而是一个逐步成长的学习工具。

你可以把它理解成一个服务个人长期学习的工作台：

- 放学习资料
- 写学习笔记
- 安排学习计划
- 记录学习进度
- 以后让 AI 帮你总结、解释和推荐

V1 第一阶段先服务两个真实学习方向：

- AI 学习
- 雅思英语学习

## 什么是 README

README 是项目说明书。

打开一个项目时，通常应该先看 README。它会告诉你：

- 这个项目是做什么的
- 当前做到哪一步
- 项目有哪些文档
- 下一步应该做什么

## 什么是 docs 文件夹

`docs` 是 documentation 的缩写，意思是文档。

这个文件夹专门用来放项目说明、规划、设计和学习路线。

## 为什么现在不急着写代码

因为你是第一次做 Codex 项目，最重要的是先建立项目意识。

写代码之前应该先知道：

- 我要解决什么问题
- 第一版要做多小
- 哪些功能以后再做
- 每个文件的作用是什么

这样后面即使 Codex 帮你写代码，你也能理解它在做什么。

现在 V1 已经确认：

- 管理学习主题
- 管理学习资料
- 安排今日学习计划
- 记录学习笔记
- 记录学习进度

这些就是第一版要做的范围。

## 现在应该怎么读这些文档

建议顺序：

1. 先读 `README.md`
2. 再读 `docs/newbie-guide.md`
3. 再读 `docs/project-plan.md`
4. 最后看 `docs/feature-list.md` 和 `docs/learning-map.md`

## 下一步建议

下一步不要急着做完整系统。

建议先做两件事：

1. 初始化 Git，让项目可以保存版本
2. 进入 V1 开发阶段，先确定技术路线和最小项目结构
