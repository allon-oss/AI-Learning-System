# Personal Learning System（AI辅助个人学习系统）入门说明

这份说明面向第一次访问项目的读者，无需编程基础。当前版本已经完成公开作品展示版改造，可以在浏览器中体验现有学习流程。

## 这个项目是什么

Personal Learning System（AI辅助个人学习系统）是一个面向不同学习领域的个人学习工作台，帮助你整理主题与资料、安排计划、记录笔记和学习进度。

项目从 AI 学习与雅思备考的个人需求出发，随着自定义学习方向等能力完善，逐渐扩展为通用个人学习管理系统。页面中的 AI 与雅思内容是虚构示例，用户可以建立适合自己的学习方向。

AI 辅助记录是项目特色：描述一次学习，生成草稿，检查并修改后再保存。目前使用本地规则模拟，未接入真实大模型，也不提供 AI 总结、解释或推荐。

## 已经可以做什么

- **学习主题：** 新建、编辑、建立父子关系、排序、归档与恢复，并新增自定义学习方向。
- **学习资料：** 保存资料基础信息、关联主题、查看、编辑、删除和维护资料整体状态。
- **学习计划：** 单条或批量录入今日计划，安排未来任务、补录历史计划，分别标记完成或取消完成。
- **学习记录：** 记录时长、完成度和简短总结，关联资料或计划，补录、编辑和删除。
- **学习笔记：** 保存理解、疑问或错题思路，并关联主题、资料和计划。
- **描述生成草稿：** 将多主题描述拆成可编辑草稿，逐条确认保存或放弃。

学习记录、计划完成状态和资料整体状态各自独立。一次学习完成 100%，不会自动把关联任务或整份资料标记为完成。

## 第一次如何体验

1. 下载或克隆项目，在浏览器中打开根目录的 `index.html`；页面运行不需要安装依赖或配置 API Key。
2. 在没有本站数据的浏览器环境中，首次打开会载入完整虚构示例，概览显示 75 分钟、2 条学习记录。
3. 点击“查看今日任务”，了解示例计划；再点击“体验描述生成草稿”，使用 [README 的三分钟体验步骤](../README.md#三分钟体验)。
4. 逐条检查草稿后保存，观察学习记录和概览更新。生成草稿本身不会保存正式记录。

浏览器需要允许本地存储；本地文件方式受限时，可通过本地静态 HTTP 服务访问项目。详细运行和测试说明见 [README](../README.md#本地运行与测试)。

## 示例与个人数据的边界

- 初始内容为虚构示例，不是作者的真实学习成绩或私人记录。
- 修改只保存在当前浏览器，没有登录或跨设备同步；清理浏览器数据可能丢失记录。
- 已有任一类项目存储数据时，不会自动插入或覆盖示例，包括已有空数组和异常内容。
- 示例日期在首次初始化时生成，之后保持不变；再次访问时，可以在历史视图中查看早先的任务。
- 如需重新体验初始示例，使用没有本站数据的独立浏览器配置或临时浏览环境，无需清空个人记录。
- 学习资料仅保存基础信息，不上传文件，也不提供资料正文阅读。
