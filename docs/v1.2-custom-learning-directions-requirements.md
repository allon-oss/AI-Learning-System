# V1.2 第一阶段：自定义学习方向

**状态：需求已确认，尚未开发**

**确认日期：2026-08-25**

## 1. 背景与目标

当前系统仅在新建主题表单中固定提供“AI 学习”和“雅思英语学习”两个学习方向。用户无法把摄影等新的长期学习领域记录到系统中。

本阶段的目标是让用户能够新增自定义学习方向，并在新建学习主题时选择它，同时保证已有主题及其资料、计划、笔记和进度关联完全不受影响。

## 2. 功能范围

### 2.1 默认方向与旧数据兼容

- 学习方向使用独立的本地保存列表管理，不与主题数据混存。
- 默认方向固定为“AI 学习”和“雅思英语学习”。
- 对已有用户数据：如果尚未保存学习方向列表，首次加载时应提供上述两个默认方向。
- 不修改已有主题的 `direction` 字段，也不修改资料、计划、笔记或进度记录中的任何关联字段。
- 若旧主题中存在不在方向列表中的方向名称，主题列表和历史关联仍应正常显示该名称；本阶段不自动删除、改名或迁移这类旧数据。

### 2.2 新增自定义方向

- 用户可在“新建学习主题”表单中打开“新增学习方向”输入区。
- 用户填写方向名称后可保存为新的学习方向，例如“摄影学习”。
- 保存成功后，新方向立即出现在学习方向下拉框中，并自动成为当前新主题选中的方向。
- 刷新页面后，新增方向仍可选择。
- 新增时必须去除名称两端空格。
- 不允许保存空名称。
- 不允许保存与现有方向完全相同的名称；相同名称的判断以去除首尾空格后的结果为准。
- 失败时保留当前输入并显示明确原因；取消新增时不保存任何方向数据。

### 2.3 新建主题联动

- 新建主题只能从学习方向下拉框中选择默认方向或已保存的自定义方向。
- 选择一个方向后，父主题下拉框只显示同一方向且未归档的主题。
- 新建主题仍沿用当前同方向、同父主题范围内的追加排序规则。
- 编辑已有主题时，学习方向继续只读，不允许通过本阶段变更已有主题所属方向。

## 3. 不包含内容

- 不实现学习方向重命名。
- 不实现学习方向删除、归档、恢复或排序。
- 不实现方向说明、图标、颜色、统计或筛选。
- 不迁移、修复或批量修改已有主题的学习方向。
- 不改变 V1.1 P2-P0 的主题编辑、归档、恢复与历史关联保护规则。

## 4. 页面与反馈

- 在“新建学习主题”表单的“学习方向”区域提供“新增学习方向”入口。
- 新增入口展开轻量输入区，包含方向名称输入框、“保存方向”和“取消”操作。
- 保存成功后给出明确成功反馈；输入为空或重复时，在输入区给出对应错误提示。
- 编辑主题时不显示新增方向入口，且学习方向选择控件维持禁用状态。
- 页面在 390px 宽度下不得出现横向溢出；新增方向后焦点应留在可继续填写主题的表单中。

## 5. 数据设计

- 新增独立的本地存储键保存方向名称数组，数组顺序即下拉框显示顺序。
- 方向列表的标准化规则应保证默认方向存在、过滤非字符串与空白项，并去除重复项，同时保留用户新增方向的先后顺序。
- 新增方向的纯数据操作应返回标准化后的方向列表与明确结果，以便页面层展示成功或失败反馈。
- 主题的 `direction` 字段继续存储方向名称，不新增方向 ID，也不修改既有数据模型的关联结构。

## 6. 验收与测试

### 6.1 自动测试

- 空、异常或不存在的方向列表能标准化为两个默认方向。
- 已有自定义方向会保留，默认方向不会丢失或重复。
- 新增“摄影学习”后结果包含该方向且顺序稳定。
- 空白名称与去除首尾空格后重复的名称被拒绝。
- 新主题使用自定义方向时，父主题只显示该方向的活动主题，且新主题排序正确。
- 现有 AI 学习、雅思英语学习主题，以及它们关联的资料、计划、笔记和进度记录，在方向操作后保持原值不变。

### 6.2 页面回归测试

- 新建主题页面可新增“摄影学习”，成功提示明确，方向自动选中。
- 用“摄影学习”可正常新建主题，并在刷新页面后仍能在下拉框中选择。
- 编辑已有主题时，学习方向继续不可修改，且不显示新增方向入口。
- 空方向、重复方向与取消新增均不会污染本地保存的数据。
- AI 学习与雅思英语学习的既有主题、资料、计划、笔记、进度记录和归档主题页面均正常显示。
- 页面无 JavaScript 错误，390px 宽度无横向溢出。
