# 项目开发路线图

这份文档用来规划 Personal Learning System（个人学习系统）的开发顺序。

## 第 0 阶段：项目规划

目标：先想清楚项目要做什么。

当前状态：已完成。

已经完成的事情：

- 创建 README
- 创建项目规划文档
- 创建功能清单
- 创建个人学习路线
- 明确 V1 最小功能
- 明确 V1 每日使用流程
- 明确 V1 需要记录的数据
- 明确 V1 暂时不做的功能
- 明确未来 AI 扩展方向

为什么先做这一步：

如果一开始直接写代码，很容易不知道自己在做什么，也容易越做越乱。先写规划，可以让后面的每一步都有方向。

## 第 1 阶段：建立项目基础

目标：让项目有一个可以长期维护的基础结构。

要完成的事情：

- 初始化 Git 版本管理
- 确定使用什么技术
- 创建基础项目结构
- 写清楚如何启动项目
- 保持 README 和 docs 文档同步更新

为什么做这一步：

项目基础就像房子的地基。地基清楚，后面加功能才不容易混乱。

## 第 2 阶段：做最小可用版本

目标：做出一个简单但真的能用的版本。

V1 主要服务两个学习方向：

- AI 学习
- 雅思英语学习

V1 必须功能：

- 学习主题管理
- 学习资料管理
- 今日学习计划
- 学习笔记
- 学习进度记录

为什么先做这些：

这些功能是个人学习系统的核心。即使暂时没有 AI，它也能帮助我管理学习过程。

V1 的判断标准：

- 我每天能打开系统安排学习任务
- 我能记录 AI 学习和雅思学习的资料
- 我能写下学习笔记、错题原因和遇到的问题
- 我能看到今天学了什么、用了多久、完成了多少

## 第 3 阶段：增加数据保存能力

目标：让学习内容可以被长期保存。

可能的选择：

- 初期使用本地文件保存
- 后续使用 SQLite 数据库
- 再后续考虑云端数据库

为什么分阶段做：

数据库对新手来说有一定复杂度。先用简单方式理解数据，再升级会更稳。

## 第 4 阶段：加入 AI 辅助功能

目标：让 AI 真正帮助个人学习，而不是只做装饰。

可能的 AI 功能：

- 总结学习笔记
- 解释不懂的概念
- 根据目标生成学习计划
- 根据学习记录推荐下一步
- 自动生成复习题
- 基于个人资料和笔记做 RAG 知识库问答
- 整理纸质资料拍照识别后的文字内容

为什么后面再加 AI：

AI 功能需要依赖已有的学习内容。如果没有笔记、资料和计划，AI 就没有足够的上下文来帮我。

## 第 5 阶段：优化界面和体验

目标：让系统更好用、更清晰。

可以优化的地方：

- 页面布局
- 搜索和筛选
- 进度统计
- 学习提醒
- 数据导出

为什么最后再做：

先保证功能正确，再优化外观和体验。这样不会一开始就陷入细节。
