# Personal Learning System 项目状态

## 项目定位

Personal Learning System（个人学习系统）

目标：
建立一个个人学习工作台，记录学习主题、资料、计划、笔记和进度，为未来 AI 辅助学习提供数据基础。

当前学习方向：
- AI学习
- 雅思英语学习


## V1核心目标

V1不是做强大的AI系统，而是先建立稳定的学习记录流程。

功能：

1. 学习主题管理
记录：
“我正在学习什么”

2. 学习资料管理
记录：
“我使用什么资料学习”

3. 今日计划
记录：
“今天学习什么”

4. 学习笔记
记录：
“我学到了什么”

5. 学习进度
记录：
“完成了多少”

### 学习资料管理 V1.1

状态：
已完成，已测试通过

目标：
把分散的学习资料关联到对应学习主题，并记录资料状态。

实现：
- 查看全部学习资料
- 新增学习资料
- 查看资料详情
- 将资料关联到学习主题
- 在主题详情页显示当前主题的相关资料
- 从主题详情页快速新增该主题的资料
- 编辑资料标题、所属主题、资料类型和学习状态
- 删除资料
- 删除前显示确认提示
- 修改或删除后同步更新资料列表和主题详情
- 本地保存资料数据

V1.1 仍然不做：
- 上传文件
- OCR识别
- AI自动整理
- 自动抓取网页信息
- 复杂搜索和筛选
- 多主题关联

### 学习计划 V1

状态：
已完成，已测试通过

目标：
记录“今天要学什么”，把学习主题和学习资料转化为每日具体学习任务。

## 下一步

建议开发第四个核心功能：学习笔记。

原因：
学习主题、学习资料和今日学习计划已经建立，下一步需要记录“我学到了什么”。

学习笔记可以把每天的学习任务沉淀为可回顾的内容：
1. 选择对应学习主题
2. 可选择关联学习资料
3. 可选择关联今日学习计划
4. 记录学到的内容、问题和总结
5. 后续再关联学习进度
