# Personal Learning System 项目状态

## 项目定位

Personal Learning System（个人学习系统）

目标：
建立一个个人学习工作台，记录学习主题、资料、计划、笔记和进度，为未来 AI 辅助学习提供数据基础。

当前学习方向：
- AI学习
- 雅思英语学习


## V1核心目标

V1不是做强大的AI系统，而是先建立稳定的学习记录流程。

功能：

1. 学习主题管理
记录：
“我正在学习什么”

2. 学习资料管理
记录：
“我使用什么资料学习”

3. 今日计划
记录：
“今天学习什么”

4. 学习笔记
记录：
“我学到了什么”

5. 学习进度
记录：
“完成了多少”

### 学习资料管理 V1.1

状态：

### 学习笔记 V1

状态：
已完成，已测试通过

目标：
记录“我学到了什么”，并将学习过程中的思考、总结和收获关联到已有学习主题、学习资料和学习计划。

实现：
- 创建学习笔记
- 必填笔记标题、笔记内容和所属学习主题
- 可选关联学习资料和学习计划
- 根据所选主题展示对应的资料和计划关联项
- 查看笔记列表和完整详情
- 按最后更新时间展示笔记列表
- 编辑笔记，并保留创建时间、更新最后更新时间
- 删除笔记前显示确认提示
- 删除后同步更新笔记列表和详情
- 本地保存笔记数据

V1 暂时不做：
- AI 自动总结或自动生成笔记
- 富文本编辑器、附件和图片
- 搜索、标签和关键词
- 知识图谱、笔记引用和复盘系统

### 学习进度记录 V1

状态：
已完成，已测试通过

目标：
记录每次实际学习的时长、完成度和简短总结，让系统能够回答“完成了多少”。

实现：
- 新增独立的学习进度记录页面
- 自动记录创建当天的本地日期
- 必填关联一个学习主题
- 可选关联学习资料和学习计划
- 根据所选主题联动显示可关联的资料和计划
- 记录实际学习时长（分钟）
- 记录本次完成度（0-100）
- 根据完成度自动显示未完成、进行中或已完成状态
- 记录可选的简短总结，不替代学习笔记
- 支持查看全部进度记录、编辑和删除
- 显示累计学习时长、记录次数和最近记录日期
- 在主题详情页显示累计时长、记录次数和最近学习进度
- 在资料和计划区域显示关联进度摘要
- 删除关联资料或计划后保留历史进度，并显示原关联内容已删除
- 本地保存进度记录数据

数据结构：
- `id`
- `date`
- `topicId`
- `resourceId`
- `planId`
- `durationMinutes`
- `completionPercent`
- `reflection`
- `createdAt`
- `updatedAt`

测试：
- 新增、编辑、删除进度记录
- 主题、资料和计划的关联筛选
- 完成度状态显示
- 主题、资料和计划的进度摘要
- 删除关联数据后的历史记录保留
- 桌面与移动端页面布局

V1 暂时不做：
- 手动补记历史学习日期
- 学习位置记录
- 资料总进度自动计算
- 自动同步计划完成状态
- 筛选、搜索、图表和连续学习统计
- 周报、月报、提醒和 AI 学习建议
