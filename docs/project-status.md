# Personal Learning System 项目状态

## 项目定位

Personal Learning System（个人学习系统）

目标：
建立一个个人学习工作台，记录学习主题、资料、计划、笔记和进度，为未来 AI 辅助学习提供数据基础。

当前学习方向：
- AI学习
- 雅思英语学习


## V1核心目标

V1不是做强大的AI系统，而是先建立稳定的学习记录流程。

功能：

1. 学习主题管理
记录：
“我正在学习什么”

2. 学习资料管理
记录：
“我使用什么资料学习”

3. 今日计划
记录：
“今天学习什么”

4. 学习笔记
记录：
“我学到了什么”

5. 学习进度
记录：
“完成了多少”

## 当前开发

### 学习资料管理 V1

目标：
把学习资料关联到对应主题，并记录资料状态。

V1只做：
- 手动记录资料

暂不做：
- 自动上传
- OCR识别
- AI自动整理
