# 个人学习路线

这份文档用来规划我自己的长期学习内容。AI 可以是重点学习方向之一，但这个系统不只服务 AI 学习，也可以用于编程、英语、阅读、职业技能等主题。

V1 第一阶段先服务两个真实学习方向：

- AI 学习
- 雅思英语学习

## 第 1 步：确定学习方向

要理解的内容：

- 我现在最想学习什么
- 这个学习方向为什么重要
- 我希望通过学习解决什么问题
- 哪些主题需要优先学习

当前优先方向：

- AI 学习：理解 AI 基础、Prompt、编程基础和 AI 应用开发
- 雅思英语学习：提升听力、阅读、写作、口语、词汇和真题练习能力

为什么先学这些：

先确定方向，后面整理资料、写计划、记录笔记时才不会迷路。

## 第 2 步：建立学习方法

要学习的内容：

- 如何把大目标拆成小任务
- 如何记录学习资料
- 如何写自己的理解
- 如何复盘学习效果
- 如何判断一个资料是否值得继续学

为什么学这些：

个人学习系统不是单纯存资料，而是帮助自己形成稳定的学习习惯。

V1 的每日学习方法：

- 学习前先定今日计划
- 学习中记录资料、重点、错题和问题
- 学习后记录实际时间、完成度和复盘
- 每周回看哪些主题推进了，哪些问题重复出现

## 第 3 步：学习编程基础

建议学习内容：

- 文件和文件夹
- Markdown 文档
- Git 基础
- HTML、CSS、JavaScript 基础
- 前端页面是什么

为什么要学编程基础：

不需要一开始成为程序员，但需要理解项目是怎么组织和运行的。

## 第 4 步：学习 Web 应用基础

建议学习内容：

- 什么是前端
- 什么是后端
- 什么是数据库
- 页面、组件、数据之间的关系
- 本地开发环境是什么

为什么学这些：

个人学习系统更适合做成网页应用。理解 Web 应用基础后，就能看懂项目结构。

## 第 5 步：学习 AI 辅助能力

建议学习内容：

- 如何使用 ChatGPT 或 Codex
- 如何清楚地提出问题
- 如何让 AI 帮助拆解任务
- 如何判断 AI 的回答是否可靠
- Prompt 设计
- API 是什么
- 如何调用 AI 模型
- 如何把用户输入发送给 AI
- 如何把 AI 返回的内容展示出来

为什么最后学这些：

AI 辅助能力需要前面的学习内容支撑。先理解个人学习流程，再接入 AI，学习曲线会更平滑。

未来可以加入的 AI 能力：

- AI 总结每日或每周学习记录
- AI 根据学习进度生成下一步计划
- AI 根据笔记和资料回答问题
- RAG 知识库，用自己的资料和笔记做问答
- 纸质资料拍照整理，把图片中的内容转成可复习资料
