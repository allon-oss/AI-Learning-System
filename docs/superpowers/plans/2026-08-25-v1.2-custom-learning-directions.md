# V1.2 自定义学习方向 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让用户新增并持久保存自定义学习方向，并在新建主题时立即选择它，不影响已有主题或任何关联数据。

**Architecture:** 在 `src/data-model.js` 中集中处理默认方向、列表标准化和新增校验；它们是无副作用的纯函数。浏览器层在 `src/app.js` 使用独立 Local Storage 键保存方向列表，重渲染下拉框、父主题选项和反馈控件；主题的 `direction` 仍为名称字符串，既有排序、归档和关联结构不变。

**Tech Stack:** 原生 HTML、CSS、浏览器 JavaScript、Local Storage、Node.js 内置 `node:test`、Playwright 页面回归测试。

**Spec:** `docs/v1.2-custom-learning-directions-requirements.md`

## Global Constraints

- 默认方向必须保留“AI 学习”和“雅思英语学习”，并固定在列表前两项。
- 只实现新增方向；不得实现改名、删除、归档、恢复、排序或迁移。
- 不得改写已有主题的 `direction`，也不得改写资料、计划、笔记或进度的关联字段。
- 编辑已有主题时，学习方向必须只读，并隐藏新增方向入口。
- 新建主题时父主题只显示同一方向、未归档的主题；同级追加排序保持不变。
- 方向名称必须裁剪首尾空格；空名称和裁剪后重复名称必须被拒绝。
- 每个任务均先写失败测试，再作最小实现并运行验证。最终在独立浏览器资料目录完成页面回归和 390px 宽度检查。

- [ ] **Step 3: 最小实现默认方向与标准化**

在 `src/data-model.js` 顶层定义并导出不可变默认数组。实现必须不改动参数，先加入默认方向，再按输入中首次出现的顺序加入裁剪后非空且不重复的字符串。

```js
const DEFAULT_LEARNING_DIRECTIONS = ["AI 学习", "雅思英语学习"];

function normalizeLearningDirections(directions) {
  const normalized = [...DEFAULT_LEARNING_DIRECTIONS];
  (Array.isArray(directions) ? directions : []).forEach((direction) => {
    const name = typeof direction === "string" ? direction.trim() : "";
    if (name && !normalized.includes(name)) normalized.push(name);
  });
  return normalized;
}
```
