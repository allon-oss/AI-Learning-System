## Task 2：主题编辑与安全父主题选择

### 验收前基线

- 打开任一主题详情时，没有“编辑主题”按钮。
- “新建主题”表单只能创建主题，不能预填已有主题数据。

### 编辑基本信息

- 在主题详情点击“编辑主题”，确认表单预填主题名称、学习方向、父主题、学习状态和描述；描述在本任务中为只读。
- 修改主题名称和学习状态并保存；确认详情和列表立即更新，刷新页面后仍保留。
- 编辑时学习方向显示但不可修改；提交后主题学习方向保持原值。
- 点击“取消”后，确认表单关闭且刷新页面后原数据未改变。

### 父主题保护与排序

- 编辑根主题时，父主题下拉项不包含该主题本身和任何子孙主题。
- 父主题下拉项不包含不同学习方向的主题。
- 将主题移动到一个允许的同方向父主题下并保存；确认主题显示在新父主题的子主题列表中，刷新后仍保留。
- 若新父主题已有子主题，确认移动后的主题排在这些同级主题之后。

### 基础可用性

- 保存后焦点回到已更新主题的详情区域或主题卡片，键盘可继续操作。
- 桌面宽度与 390px 宽度下，编辑表单、按钮和父主题下拉框不产生横向滚动。
- 浏览器控制台没有 JavaScript 错误。
