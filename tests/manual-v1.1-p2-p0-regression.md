# V1.1 P2 P0 主题治理回归清单

测试时使用独立浏览器资料目录，避免覆盖日常学习数据。每个保存场景后刷新页面，确认 Local Storage 数据仍保留。

## Task 2：主题编辑与安全父主题选择

### 验收前基线

- 打开任一主题详情时，没有“编辑主题”按钮。
- “新建主题”表单只能创建主题，不能预填已有主题数据。

### 编辑基本信息

- 在主题详情点击“编辑主题”，确认表单预填主题名称、学习方向、父主题、学习状态和描述；描述在本任务中为只读。
- 修改主题名称和学习状态并保存；确认详情和列表立即更新，刷新页面后仍保留。
- 编辑时学习方向显示但不可修改；提交后主题学习方向保持原值。
- 点击“取消”后，确认表单关闭且刷新页面后原数据未改变。

### 父主题保护与排序

- 编辑根主题时，父主题下拉项不包含该主题本身和任何子孙主题。
- 父主题下拉项不包含不同学习方向的主题。
- 将主题移动到一个允许的同方向父主题下并保存；确认主题显示在新父主题的子主题列表中，刷新后仍保留。
- 若新父主题已有子主题，确认移动后的主题排在这些同级主题之后。

### 基础可用性

- 保存后焦点回到已更新主题的详情区域或主题卡片，键盘可继续操作。
- 桌面宽度与 390px 宽度下，编辑表单、按钮和父主题下拉框不产生横向滚动。
- 浏览器控制台没有 JavaScript 错误。

## Task 3：级联归档、影响确认与整组恢复

### 归档确认与数据保护

- 在活动主题详情确认显示“归档主题”按钮。
- 选择一个带子主题、资料、计划、笔记和进度记录的父主题；点击归档后，确认提示显示主题、资料、计划、笔记、进度五项数量。
- 确认提示明确说明：历史数据会保留、归档后不能新增或改关联、本次不会删除数据。
- 在确认提示选择取消；确认页面和 Local Storage 均不改变。
- 在确认提示选择继续；确认父主题及全部子孙主题从正常主题列表消失，资料、计划、笔记和进度记录的 `topicId` 保持不变。
- 归档没有关联数据的叶子主题；确认数量为主题 1、其余四类记录均为 0。

### 已归档主题查看与恢复

- 点击“查看已归档主题”，确认可按学习方向和父子层级查看归档主题，所有条目显示“已归档”。
- 点击归档主题查看详情；确认详情显示归档状态，不显示编辑或归档按钮，也不显示“新增该主题的资料”按钮。
- 归档组根主题显示“恢复主题”按钮；子主题只显示“随父主题归档”，没有独立恢复按钮。
- 恢复根主题后，根主题与全部子孙主题一起回到正常主题列表；刷新页面后状态保持。

### 基础可用性

- 归档、取消归档和恢复后，主题详情仍显示有效内容或明确的空状态。
- 桌面宽度与 390px 宽度下，归档入口、归档列表和操作按钮不产生横向滚动。
- 浏览器控制台没有 JavaScript 错误。
