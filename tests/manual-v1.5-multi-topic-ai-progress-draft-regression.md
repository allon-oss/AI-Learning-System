# V1.5 多主题 AI 学习进度草稿人工验收清单

> 安全提示：请使用独立的 Edge 测试配置文件，或先备份并使用专门的测试 Local Storage。不要直接在唯一一份真实学习数据上执行删除、归档和清空操作。

## 验收前准备

1. 打开“学习进度”页面，记下当前已保存进度数，以下称为 `N`。
2. 准备两个活动主题：
   - `Codex 实践`，学习方向为“AI 学习”；
   - `词汇`，学习方向为“雅思英语学习”。
3. 为当天分别准备一条计划：`练习 Codex` 和 `背单词`。
4. 如需核对浏览器存储，进度键为 `personal-learning-system-progress-records`；草稿队列不应出现新的 Local Storage 键。

## 1. 主流程：一段描述生成两条草稿

输入：

```text
今天 Codex 学了40分钟，背了40个单词。
```

预期：

- 按顺序出现两张卡片：先 Codex，后背单词。
- Codex 草稿关联“AI 学习 / Codex 实践”和当天 Codex 计划，时长为 40 分钟。
- 雅思草稿关联“雅思英语学习 / 词汇”和当天背单词计划。
- “40 个单词”保留在总结中，雅思时长为空，不得自动填 40 分钟。
- 两条完成度都为空。
- 生成前存储记录数为 `N`，生成后仍为 `N`。

## 2. 切换草稿时保留各自修改

操作：Codex 完成度填 70；切到雅思，时长填 25、完成度填 80；再来回切换。

预期：两条草稿分别保留自己的修改，字段不会串到另一条；存储记录数始终为 `N`。

## 3. 保存第一条不影响第二条

操作：在 Codex 草稿上点击“确认并保存此条”。

预期：

- 保存前记录数为 `N`，保存成功后为 `N + 1`。
- 新记录主题为 Codex、时长 40、完成度 70。
- 队列只移除 Codex，雅思草稿仍存在，时长 25、完成度 80 和总结均保持不变。

## 4. 放弃剩余草稿不写入记录

操作：在雅思草稿点击“放弃此条”，先取消确认，再次点击并确认放弃。

预期：

- 取消时队列和表单不变，记录数仍为 `N + 1`。
- 确认放弃后队列清空并恢复普通手动新增状态。
- 放弃前后记录数都为 `N + 1`，不得新增第二条记录。

## 5. 校验失败只阻止当前保存

操作：再次生成两条，不填写 Codex 完成度就尝试保存；再把 Codex 主题归档或模拟主题失效后尝试保存。

预期：两次保存都被阻止，两条草稿的顺序和内容保持；操作前后记录数均不变。恢复测试主题后再继续。

## 6. 浏览器存储失败保持原状

操作：在测试环境中模拟 Local Storage 写入失败，再保存当前草稿。

预期：显示“进度保存失败”；记录数保存前后相同；队列顺序、活动草稿和表单值不变。恢复正常存储后才能保存。

## 7. 双击不会重复保存

操作：补齐当前草稿后快速双击“确认并保存此条”。

预期：保存前记录数为 `N`，完成后只变为 `N + 1`；只移除当前一条，不得出现两条重复记录，也不得误保存下一条。

## 8. 重新生成的取消、失败和成功

操作：队列非空时再次点击生成，依次测试取消替换、Provider 失败和确认后成功生成。

预期：

- 取消时不调用生成，旧队列和当前修改保留，记录数不变。
- 失败时显示错误，旧队列和当前修改保留，记录数不变。
- 只有成功返回完整结果后才一次性替换旧队列，记录数仍不变。

## 9. 编辑已有进度时挂起并恢复队列

操作：生成两条并修改后，点击一条已保存进度的“编辑”；分别测试保存修改和取消编辑。

预期：编辑期间 AI 面板隐藏；退出编辑后两条队列按原顺序恢复，同一活动草稿及修改值保留。只更新那条已有记录，队列草稿不会被保存或移除；总记录数不增加。

## 10. 歧义、归档和关联删除保护

操作：分别制造重名主题、同主题多条当天计划、归档主题，并在生成后删除某条草稿关联的资料或计划。

预期：

- 无法唯一判断时主题或计划保持为空并给出提示，不按数组顺序猜测。
- 归档主题不被新草稿关联。
- 删除资料或计划后，只清除对应草稿的关联，其他草稿不变。
- 未点击成功保存前，记录数始终不变。

## 11. 刷新与跨午夜行为

操作：保存一条、保留一条未确认草稿后刷新页面；另在测试环境模拟跨过本地午夜。

预期：

- 刷新前若记录数为 `N + 1`，刷新后仍为 `N + 1`；已保存记录存在，未保存队列消失。
- 午夜前生成的草稿保持原日期，并可按历史日期保存；保存前后记录数只增加 1。
- 午夜后重新生成的草稿使用新的本地日期。

## 12. 390px 窄屏与错误检查

操作：把视口调整为 390 × 844，完成生成、切换、修改、保存一条和放弃一条的完整流程。

预期：页面无横向滚动；卡片、输入框和按钮完整可用；保存使记录数准确增加 1，放弃不增加记录；控制台没有 JavaScript 错误。
