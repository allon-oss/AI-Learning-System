# V1.1 P1 按日期计划回归清单

测试时使用独立的浏览器 Local Storage，避免覆盖日常学习数据。每个场景完成后刷新页面，确认数据仍保留。

## 创建与数据兼容

- 新建计划时，“计划日期”默认当天，且不能选择昨天或更早日期。
- 新建今天和未来计划，分别检查保存的 `date`、`priority`（默认“中”）和 `estimatedMinutes`（空值为 `null`）字段。
- 输入 `0`、负数、小数或非数字预计时长，确认页面拒绝保存并说明原因；留空可以保存。
- 在 Local Storage 预置缺少 `priority` 和 `estimatedMinutes` 的旧计划，刷新后确认它仍可见，显示默认“中”和未填写预计时长。
- 在 Local Storage 预置 `date: "旧格式"` 或 `date: "2026-02-30"` 的旧计划，刷新后确认原始值没有被页面启动写回修改，并在“历史”中显示“日期异常”。

## 三个计划视图与跨日场景

- “今天”只显示当天任务，并保留完成和取消完成操作；主题详情和资料详情的今日摘要只统计当天任务。
- “未来”只显示未来日期任务，按最近日期在前；同一天的任务保持保存数组顺序。
- 将一条昨天未完成计划保存在 Local Storage，确认其只出现在“历史”，显示“已逾期”和原计划日期，且不会被自动改成今天。
- 将一条昨天已完成计划保存在 Local Storage，确认其可在“历史”回看，不显示逾期。
- “历史”中的有效日期按最近日期在前；无效日期记录保留在有效日期记录之后，并保持彼此原有顺序。

## P0 回归

- 完成或取消完成计划后，关联资料的“资料整体状态”不改变。
- 资料详情的“今日关联任务状态”仍只统计今天的关联计划。
- 主题列表的同级排序仍稳定；移动主题和刷新页面后顺序保持。
- 窄屏（390px）下计划标签、表单和任务卡不产生横向滚动。
