## 页面级回归

测试环境：系统 Edge 无界面模式，使用独立浏览器上下文和独立 Local Storage，不读取或修改用户日常浏览器数据。

结果：16 项通过，0 项失败。

### 主题稳定排序

- 默认 AI 主题顺序为“AI 基础 → Prompt Engineering”。
- 上移 Prompt Engineering 后，顺序变为“Prompt Engineering → AI 基础”。
- 排序后键盘焦点保留在被移动主题上，选中主题具备可访问状态。
- 刷新页面后调整结果保持不变。
- 新建“AI 工作流 P0 测试”后，它位于同级列表末尾。
- 异常格式的原始主题存储不会在页面启动时被覆盖。

### 状态语义区分

- 新建一份整体状态为“学习中”的资料并关联今日任务。
- 完成任务后显示“今日任务已完成并保存”。
- 任务卡显示“今日任务状态：已完成”。
- 资料 Local Storage 中的整体状态仍为“学习中”。
- 资料详情同时显示“资料整体状态”和“今日关联任务状态”。
- 资料详情的任务摘要显示“已完成 1/1”。
- 取消完成后显示明确反馈，任务状态恢复为“未完成”。
- 取消完成后资料详情的任务摘要显示“已完成 0/1”。
- 完成和取消完成都不会改变资料整体状态。

### 页面稳定性

- 页面运行期间没有 JavaScript 错误。
- 390 像素宽度下没有横向溢出。
