# V1.2 第一阶段：自定义学习方向人工回归清单

测试前使用独立浏览器资料目录或清空测试 Local Storage，避免覆盖日常学习数据。每个保存场景后刷新页面，确认结果保留。

## 新增与持久化

1. 打开“新建主题”，确认学习方向默认有“AI 学习”和“雅思英语学习”。
2. 点击“新增学习方向”，输入“摄影学习”，点击“保存方向”。
3. 确认成功提示明确、下拉框自动选中“摄影学习”，然后创建一个摄影主题。
4. 刷新页面并再次打开新建主题，确认“摄影学习”仍可选择。
5. 在“摄影学习”下创建子主题，确认父主题列表仅包含摄影方向的活动主题，不包含 AI 或雅思主题。

## 输入保护

1. 打开新增方向输入区，直接保存；确认提示“请输入学习方向名称”，不产生新的方向。
2. 输入已有方向（含首尾空格，例如“ AI 学习 ”）并保存；确认提示重复，输入内容保留，方向列表不重复。
3. 输入任意名称后点击“取消”；确认输入区关闭、未保存该名称，焦点回到“新增学习方向”按钮。

## 兼容与只读保护

1. 打开已有 AI 或雅思主题进行编辑；确认学习方向不可修改，且不显示新增方向入口。
2. 检查已有主题、资料、计划、笔记、进度和已归档主题；确认名称、方向、内容和各自关联保持原样。
3. 在 390px 宽度下重复新增方向和新建主题操作；确认无横向滚动、无焦点丢失和无浏览器控制台 JavaScript 错误。
